To Run Standalone grid
----------------------
cd /d G:\_Udemy\Projects\OpenCart\Project\OpenCart0001

To Start Grid on Docker
----------------------
Open docker desktop
Open terminal
cd /d G:\_Udemy\Projects\OpenCart\Project\OpenCart0001

------------------------------
